# Project Question

## Target
PDB: 8VEZ

Protein: apx1049
Ligand: Apixaban (GG2)

## Research Question
How do mutation patterns and model confidence differ between apixaban-contact residues and non-contact residues when 8VEZ is redesigned using LigandMPNN?

## Rationale
LigandMPNN is designed to incorporate non-protein atomic context during
protein sequence design. This project investigates whether residues near
a bound small molecule show distinct redesign patterns compared with
residues outside the ligand-binding pocket.

## Planned Workflow
8VEZ structure
→ ligand-binding pocket identification
→ LigandMPNN sequence generation
→ mutation analysis
→ pocket vs non-pocket comparison
→ candidate interpretation
→ structural validation
